# Personal Portfolio Site

A simple, responsive personal portfolio website built with pure HTML5 and custom CSS. Designed to showcase my development projects, technical skills, and background without any external dependencies or heavy JavaScript frameworks.

## Live Site

🔗 **Live Portfolio:** [https://joo1232.github.io/My-Site/](https://joo1232.github.io/My-Site/)

---

## Features

- **Responsive Design:** Fits clean layouts on mobile phones, tablets, and desktop displays using CSS Grid and Flexbox.
- **Custom Dark Theme:** Uses CSS variables for color management, clean card components, and subtle hover animations.
- **Pure HTML & CSS:** Zero third-party JavaScript libraries or frameworks, keeping loading speeds fast and resource usage minimal.
- **GitHub Pages Ready:** Built with an embedded stylesheet in `index.html` for easy deployment on GitHub Pages.

---

## Website Sections

1. **About:** Brief introduction and primary areas of focus.
2. **Technical Skills:** Key highlights across frontend engineering, low-level systems, and development tools.
3. **Featured Projects:** Project cards showcasing featured repositories and technology tags.
4. **Contact & AI Disclosure:** Direct contact details and the required AI usage statement.

---

## Tech Stack

- **HTML5:** Semantic document layout
- **CSS3:** Custom variables, layout structure, and responsive styling
- **Deployment:** GitHub Pages

---

## How AI Was Used

In compliance with project guidelines, AI was used to assist with generating the initial HTML layout scaffolding and CSS resets. All styling choices, layout adjustments, content structure, and deployment steps were completed and managed manually.
